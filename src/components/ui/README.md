# project-owned UI primitives

These small components are editable source owned by the delivered template. They follow the shadcn/ui composition model: primitives stay close to native HTML, accept class names, and leave application ownership with the project.

The source is intentionally local and dependency-free. `shadcn-admin` is used only as a page structure and information architecture reference; it is not copied into the runtime.

Provenance: authored for the Shpitto template administration foundation on 2026-10-21. No hosted runtime, generated registry, or enterprise component package is required.
