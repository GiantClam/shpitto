# Default sample artwork

`alpine-studio.png` is an original illustration generated with the built-in
imagegen tool on 2026-10-17 for this template's marketing hero. It is not a
customer asset, a provider validation result, or evidence that the application
supports image generation. Keep its visible sample-artwork label when used in
the default demo. Customer customization may replace it with owned media.

The source is 1536 x 1024. The marketing page uses Next Image for responsive
delivery. Its source selection accounts for the taller cover crop, not just
the CSS element width.
